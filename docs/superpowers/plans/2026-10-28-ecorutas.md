# EcoRutas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir la app KMP Android de EcoRecicla con sesión segura, lectura local reactiva, registro/corrección offline y sincronización determinista con EcoAPI.

**Architecture:** La UI observa únicamente repositorios y `Flow` de SQLDelight. Ktor alimenta la base local; la cola usa el estado del propio pesaje, no una segunda tabla. Un `Mutex` serializa CREATE → UPDATE → ANULATE → descarga.

**Tech Stack:** Kotlin 2.4.10, Compose Multiplatform 1.11.1, Ktor 3.1.3, SQLDelight 2.1.0, Koin 4.0.2, Android API 24/36, Java 21.

**Spec:** `docs/superpowers/specs/2026-10-28-ecorutas-design.md`

**Master tracker:** `../../../../tasks/todo.md`; always read `../../../../tasks/handoff.md` before resuming.

## Global Constraints

- Base de paquete: `pe.upeu.ecorecicla`.
- Los modelos exigidos conservan nombres y tipos; solo se agregan `observacion` y `OperacionPendiente`.
- La UI nunca usa listas embebidas ni DTO remotos directamente: observa SQLDelight.
- `pesoNeto` no se envía; lo calcula EcoAPI.
- IDs locales nuevos: negativos y sin colisión incluso con tabla vacía.
- Cada fila local pertenece al usuario autenticado para no mezclar turnos.
- El cierre de sesión limpia token, bearer y sesión; pesajes pendientes requieren sincronizar o confirmar descarte.
- No se agrega navegación, abstracción o dependencia fuera de lo requerido por el examen.

## Review Focus

- Token fuera de preferencias planas y 401 limpia sesión sin borrar trabajo pendiente: Tasks 5 y 9.
- Registro sin red aparece de inmediato con ID negativo y marca pendiente: Task 6.
- Sincronización no duplica y respeta CREATE → UPDATE → ANULATE → descarga: Task 7.
- Errores 400 se muestran bajo los campos; 403 conserva sesión; 404 no reintenta: Tasks 4 y 8.
- Las cuatro pruebas mínimas y las seis de sesión 11 se ejecutan en `commonTest`: Tasks 6 y 7.
