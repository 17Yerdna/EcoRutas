# SC-D — Distintivo observable de pendientes

BaseLocal.pendientes transforma la consulta SQLDelight COUNT en Flow. El ViewModel recoge el valor; no incrementa ni decrementa un contador manual. La ruta muestra el distintivo por usuario.

Prueba con SQLite real: contador0, alta local→1, reemplazo por respuesta servidor→0. Suite completa y APK: BUILD SUCCESSFUL (`final-tests.log`).
